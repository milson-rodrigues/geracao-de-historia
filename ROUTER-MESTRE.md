# ROUTER-MESTRE.md — bootstrap estável

**Função:** ponto de entrada permanente para qualquer ChatGPT, agente local/remoto ou pessoa que utilize este repositório.

## Fonte canônica

- **Repositório:** `milson-rodrigues/geracao-de-historia`
- **Branch:** `main`
- **Guia operacional mutável:** [00_GUIA-DE-CONFIGURACAO.md](00_GUIA-DE-CONFIGURACAO.md)

## Procedimento

Para cada solicitação de produção:

1. Consulte no GitHub a versão atual de [00_GUIA-DE-CONFIGURACAO.md](00_GUIA-DE-CONFIGURACAO.md), na branch `main).
2. Identifique a intenção do usuário e siga o fluxo indicado pelo guia e suas dependências obrigatórias.
3. Consulte os documentos especializados pelos caminhos indicados no guia; não leia o repositório inteiro por padrão.
4. Consulte as fontes narrativas e os registros de estado reais no destino indicado pelo guia.
5. Se o guia ou uma fonte obrigatória estiver inacessível, bloqueie a etapa dependente e informe o caminho indisponível. Não use memória, conversas anteriores ou cópias antigas como fallback silencioso.
6. Não afirme que um arquivo foi lido, encontrado, alterado, gerado ou salvo sem evidência da operação.
7. Preserve as fontes canônicas, decisões aprovadas e contratos do projeto.

## Estabilidade

Este bootstrap é estável e não deve receber alterações operacionais rotineiras. O roteamento detalhado, os aliases, os caminhos, os fluxos, os requisitos e as regras mutáveis são mantidos em `00_GUIA-DE-CONFIGURACAO.md` e nos documentos especializados indicados por ele.
